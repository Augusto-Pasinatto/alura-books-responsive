## AluraBooks

Responsive book store website developed as part of the Alura course **HTML and CSS: Responsiveness with Mobile-First**.

> **Note:** The website content and interface are entirely in Portuguese.

### About the Project

AluraBooks is a responsive web project focused on building layouts using a **mobile-first approach**.

The project was developed to practice HTML and CSS concepts, adapting the interface for different screen sizes, including mobile devices, tablets, and desktops.

The website represents a fictional online bookstore, featuring book carousels, categories, user sections, newsletter registration, and other interface components.

### Course

- **Course:** HTML and CSS: Responsiveness with Mobile-First
  - **Level:** Intermediate
  - **Duration:** 12 hours
  - **Platform:** Alura


### Technologies

* HTML5
* CSS3
* JavaScript
* APIs
* Swiper.js

### Features

* Responsive layout for mobile, tablet, and desktop
* Mobile-first development approach
* Responsive navigation menu
* Book carousels using Swiper.js
* Search and newsletter input fields
* Responsive sections and cards
* Use of external resources and APIs
* Custom typography using Google Fonts

### Purpose

This project was created for educational purposes as part of the Alura Front-end course, with the goal of practicing responsive web development using HTML, CSS, JavaScript, and related web technologies.
